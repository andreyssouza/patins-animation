# Patins Animation

Projeto desenvolvido para praticar e revisar fundamentos de **HTML** e **animações com CSS**, inspirado em exercícios da **Rocketseat**.

## 📌 Sobre o projeto

Este projeto tem como objetivo aplicar conceitos básicos de estruturação com HTML e efeitos visuais com CSS, explorando animações, posicionamento e organização de elementos na interface.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Objetivo

- Revisar a estrutura semântica do HTML
- Praticar posicionamento com CSS
- Explorar animações e transições
- Treinar organização visual de uma página web

## 💻 Como executar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/andreyssouza/patins-animation.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd patins-animation
   ```

3. Abra o arquivo `index.html` no navegador.

## 📁 Estrutura do projeto

- `index.html` — estrutura principal da página
- `style.css` — estilos e animações do projeto

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foi possível reforçar conhecimentos sobre:

- HTML semântico
- Organização de conteúdo na página
- Propriedades de layout no CSS
- Animações e transições
- Posicionamento e responsividade básica
